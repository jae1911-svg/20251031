## 분석 메모
1. CSV가 2단 헤더 구조를 사용하므로, 분석 시 첫 두 줄을 활용해 (티커, 지표) 형태의 컬럼 이름을 재구성해야 합니다.
2. 결측치가 존재하므로 통계량 계산 전 `None` 값 필터링이 필요합니다.
3. 위 통계량은 단순 산술 평균과 표준편차를 사용했으며, 거래량은 평균 거래량으로 요약했습니다.

## 재현 방법
아래 스크립트는 Python 표준 라이브러리만으로 위 통계량을 계산하는 예시입니다.

```python
import csv, math

with open("temp.csv") as f:
    rows = list(csv.reader(f))

columns = [(ticker, metric) for metric, ticker in zip(rows[0][1:], rows[1][1:])]
records = []
for row in rows[3:]:
    if not row or not row[0]:
        continue
    values = {"Date": row[0]}
    for (ticker, metric), value in zip(columns, row[1:]):
        values[(ticker, metric)] = float(value) if value else None
    records.append(values)

# 이후 records를 순회하며 필요한 통계량을 계산합니다.
```

위 절차를 따라가면 멀티 헤더 구조를 해석하고, 각 티커별 기본 통계량과 기간별 수익률을 계산할 수 있습니다.
